# s878: list read-only local volumes, not disk images

Summary: Read-only local volumes (NTFS, write-locked cards) are now listed and marked read-only, while mounted disk images stay hidden.

- Filter is the pure `LocalVolume.shouldList`; disk images are detected with DiskArbitration (`DADiskCreateFromVolumePath` + `DADiskCopyDescription`), which only reads the mount table and so needs no entitlement. Not run inside a sandboxed app here; if DA ever fails the volume is shown rather than hidden.
- Decision 0139 updated.
